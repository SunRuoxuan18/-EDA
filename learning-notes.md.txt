STC51 两层 PCB 学习与调试记录

这是我学习 51 单片机、嘉立创EDA、两层 PCB 布局布线时的笔记。
本项目参考了 B 站课程，原理图复绘、PCB 布局布线、DRC 检查和工程整理由我完成。
注意：本文是学习记录。芯片电压范围、引脚功能和外围参数应以实际器件的数据手册为准。

项目定位：
本项目是一块面向学习的 STC51 两层最小系统板，目标是练习完整硬件设计流程。

需求整理
1，原理图设计
2，器件封装检查
3， PCB 布局
4，PCB 布线与铺铜
5， ERC/DRC 检查
6， 导出 Gerber、BOM 和工程文件
7， 后续打样、焊接与验证

预期功能：
1，USB-C 5V 供电
2，STC89C51/52 系列单片机最小系统
3，晶振与复位电路
4，串口下载/调试接口
5，按键输入
6，LED 状态指示
7，P0 口上拉
8，I/O 扩展排针
9，USB-C 供电

一：VBUS 是什么？
USB 中的 VBUS 是供电正线。普通 USB-C 取电设备中：
VBUS → 板子的 +5V 网络
GND → 板子的 GND 网络
6Pin USB-C 母座通常只有：
VBUS × 2
GND × 2
CC1
CC2
两个 VBUS 接到同一条 +5V 网络，两个 GND 接到同一条 GND 网络。
这类接口没有 D+、D-，因此只能供电，不能 USB 数据通信或 USB 下载程序。
CC1、CC2 为什么各接 5.1kΩ 到 GND？
本板是 USB-C 的受电端，因此：
CC1 → 5.1kΩ → GND
CC2 → 5.1kΩ → GND
这表示“我是需要取电的设备，请提供默认 5V”。
USB-C 可以正反插，实际只会使用 CC1 或 CC2 中的一根进行识别，因此两个都要接独立的 5.1kΩ 下拉电阻。
为什么可以增加电源开关？
常见连接：
USB-C VBUS → 电源开关 → 板载 +5V
开关不是必须，但方便：
1，不拔 USB 线也能断电；
2，调试时快速重启；
3，检查异常发热；
4，未来增加电池或其他电源时隔离电路。

二：USB-C 电源入口需要电容吗？
建议在 USB-C 的 VBUS 入口附近放：
10µF 电容；
100nF 电容。
它们并联在电源和地之间：
+5V ──┬── 10µF ── GND
　　　└── 100nF ── GND

三；LDO 与 AMS1117
LDO 是什么？
LDO 是线性稳压器，用来把较高电压变成较低、较稳定的电压：
+5V → LDO → +3.3V
什么时候需要 AMS1117-3.3？
板上有需要 3.3V 的器件时才需要，例如某些传感器、无线模块等。这块板需要3.3V供电的是LED灯电路中的LED
普通 STC89C51/52 多数使用 5V。若板上所有器件都使用 5V，通常不需要 AMS1117-3.3。
AMS1117 常见版本
AMS1117-3.3：固定输出 3.3V
AMS1117-5.0：固定输出 5V
AMS1117-ADJ：可调输出版本
ADJ 是调节脚，可调版本通过电阻设置输出电压；固定 3.3V 版本不需要分压电阻。

四：AMS1117 为什么有两个 VOUT？
常见 SOT-223 封装中：
2 脚：VOUT
背面大焊盘：VOUT
它们内部已经相连。大焊盘同时负责输出连接和散热，所以 PCB 上都要接同一条输出网络，例如 +3.3V

五：AMS1117 输入、输出为什么加电容？
典型连接：
+5V ── AMS1117 IN
　　　　│
　　　10µF
　　　　│
　　　GND  
+3V3 ── AMS1117 OUT
　　　　 │
　　　10~22µF
　　　　 │
　　　　GND  

输入和输出可再各并联一颗 100nF 陶瓷电容。
大电容：处理较慢、较大的电流变化，帮助 LDO 稳定；
小电容：处理高频尖峰和噪声。
具体输出电容的容量、类型和 ESR，优先看实际购买的 LDO 数据手册。

六：电容与去耦

去耦电容是什么？
去耦电容接在芯片电源和地之间：
VCC ──┬── 芯片电源脚
　　　│
　　100nF
　　　│
　　 GND
作用：
1，芯片瞬间需要电流时，就近提供电流；
2，吸收数字开关产生的高频噪声；
3，减少电源电压波动；
4，减少不同模块间的电源干扰。

常见电容取值
100nF：芯片电源脚附近的高频去耦
1µF：局部去耦或小模块电源缓冲
4.7~22µF：电源入口、LDO 输入输出、局部储能

为什么并联大小两个电容？
电源 ──┬── 10µF ── GND
　　　└── 100nF ── GND
10µF：储能较多，处理较慢、幅度较大的电流变化；
100nF：更擅长处理高频噪声。
它们是并联关系，不是“电流先经过大电容，再经过小电容”。

七，51 最小系统

上电复位是什么？
刚接通电源时，单片机需要先进入一个确定状态，再执行程序，这叫上电复位。

常见 51 复位电路：
VCC ── 10µF ── RST ── 10kΩ ── GND
上电瞬间，电容让 RST 暂时为高电平；随后电容放电，RST 回到低电平，单片机开始运行。
复位电路里的 10µF 可以用电解电容，也可以用陶瓷电容。若使用电解电容，要注意极性。

晶振为什么重要？
晶振给单片机提供时钟：
XTAL1 ── 晶振 ── XTAL2
　│　　　　　　　　│
负载电容　　　　 负载电容
　│　　　　　　　　│
 GND　　　　　　　GND

布局原则：
晶振尽量靠近 MCU 的 XTAL1、XTAL2；
两颗负载电容也要靠近；
晶振走线短、直、少过孔；
晶振附近不要走普通信号或大电流线；
电容地端尽快接地。

晶振旁为什么放地过孔？
地过孔让晶振负载电容的地端快速接到底层 GND 铜皮，缩小回路、减少干扰。
低频 51 板不一定必须放地过孔，但晶振、负载电容和 MCU 必须靠近。

八：I/O、按键与 LED

I/O 与 GPIO 是什么？

I/O 是 Input/Output 的缩写，GPIO 是 General-Purpose Input/Output 的缩写。
它们都是单片机与外部电路沟通的引脚：
输入：读取按键、传感器、外部电平；
输出：控制 LED、蜂鸣器、驱动器。
51 的 P0.x、P1.x、P2.x、P3.x 都可以作为 I/O 使用。

按键为什么接 I/O 和 GND？

典型接法：
P2.0 ── 按键 ── GND
松开：P2.0 依靠内部上拉，读到高电平 1；
按下：按键把 P2.0 接地，读到低电平 0。
程序检测到低电平后，可以执行提前定义好的功能，例如：
切换 LED；
数值加一；
进入设置模式；
确认或退出。

为什么选择 P2.0、P2.1 接按键？
它们不是按键专用脚，只是常见选择：
编号连续；
P2 通常有内部上拉；
不占用 P3.0/P3.1 的串口下载功能。
其他空闲的 P1、P2、P3 引脚也可以接按键。

LED 为什么阴极接 I/O？
常见低电平点亮接法：
+5V → 限流电阻 → LED 阳极
LED 阴极 → I/O
I/O 输出低电平：LED 亮；
I/O 输出高电平：LED 灭。
LED 必须串联限流电阻，常用范围是 330Ω~1kΩ。

P0 口与上拉电阻

什么是开漏？
经典 51 的 P0 常是开漏结构，可以理解为只有一个拉低开关：
P0 引脚 ── 内部开关 ── GND
输出 0：内部开关闭合，引脚被拉到 GND；
输出 1：内部开关断开，引脚悬空。

P0 为什么需要上拉电阻？

P0 没有内部主动上拉，不能主动输出高电平。作为普通 I/O 使用时，需要外接上拉：
+5V
 │
10kΩ
 │
P0.x
这样：
P0 输出 1：电阻将引脚拉高；
P0 输出 0：芯片拉低引脚，电阻限制电流；
P0 作为输入：防止引脚悬空、读数不稳定。
8 个 P0 引脚可以用独立电阻，也可以使用排阻。

九：串口与排针

P3.0、P3.1 为什么是串口？
经典 51 的硬件功能通常规定：
P3.0 = RXD：串口接收
P3.1 = TXD：串口发送
串口可用于：
STC 单片机下载；
向电脑发送调试信息；
连接蓝牙、GPS、ESP8266、串口屏等模块。

串口排针如何连接？

建议引出：
GND、5V、RXD、TXD
连接 USB 转串口模块：
下载器 TXD → 板子 RXD（P3.0）
下载器 RXD → 板子 TXD（P3.1）
下载器 GND → 板子 GND
TX 与 RX 要交叉连接。

为什么串口要引出 GND？
通信电平以 GND 为参考。下载器和目标板不共地时，通信可能不稳定或失败。
为什么引出 5V？
5V 可以：
给外接模块供电；
让 USB 转串口模块给目标板供电。
注意：如果 USB-C 和下载器都能给板子提供 5V，避免两路同时接入，以免电源回灌。

为什么大排针和下载排针重复引出 RXD/TXD/5V/GND？
它们在电气上是同一网络，只是有两个物理连接位置：
大排针：通用 I/O 扩展；
下载排针：下载时方便接线，不容易接错。
这不是两个串口。

为什么 P2.7 到 P2.0 倒序排列？
排针顺序可按照 MCU 的物理引脚顺序设计。
若芯片边缘顺序为：
P2.7 → P2.6 → … → P2.0
排针也按此排列，就可以减少走线交叉、绕路和过孔，特别适合两层板。
无论如何排列，都应在 PCB 丝印和文档中标明引脚名称、1 脚位置和电压。

PCB 布局布线
推荐布局顺序
板框与安装孔
→ USB-C、排针、按键等边缘器件
→ 电源入口与 LDO
→ MCU
→ 晶振、去耦电容、复位电路
→ LED、按键
→ 普通 I/O 外设

布局原则
USB-C、排针、按键放在板边；
MCU 放在板中心或主要接口附近；
电源区集中布置；
LDO 输入、输出电容靠近 LDO；
去耦电容靠近芯片 VCC/GND；
晶振和负载电容靠近 MCU；
LED、电解电容、二极管方向统一；
丝印不要压住焊盘；
排针和接口清楚标明 1 脚。

推荐布线顺序
USB-C VBUS 与主要电源
→ LDO 输入、输出
→ MCU 电源
→ 晶振与复位
→ 串口
→ LED、按键
→ 普通 I/O
→ 铺 GND 铜皮

两层板实践原则
顶层主要放器件和走信号；
底层尽量保持完整 GND 铜皮；
普通信号可先使用约 0.20~0.25mm 线宽；
电源线可先使用 0.40~0.60mm；
大电流电源线应根据实际电流加宽；
合理使用过孔；
走线尽量使用 45° 转角；
不要让普通信号线大面积切碎地平面；
铺铜后检查 GND 是否连通。

是否隐藏电源和地飞线？
可以临时隐藏 GND、+5V、+3V3 飞线，减少画面干扰、方便布普通信号。
但这只是显示辅助。电源布局、电源走线和地平面仍然必须认真完成，最终要恢复显示并检查所有网络连通。

ERC 和 DRC 是什么？

ERC：检查原理图的电气连接问题。
DRC：检查 PCB 的间距、短路、未连接、孔径等规则问题。
打样前应确认没有未处理的关键 ERC/DRC 错误。
